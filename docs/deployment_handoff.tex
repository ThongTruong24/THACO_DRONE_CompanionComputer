\section{Purpose and Current State}

This document is the editable implementation handoff for the Drone Edge project.
It separates features verified on the Raspberry Pi from local work that has not
been deployed. It also records the architectural and safety constraints for
future planner-driven flight-control development.

\section{Authoritative Transport Topology}

\begin{lstlisting}
FC <-> UART <-> MAVLink Router <-> MAVROS <-> autopilot-telemetry <-> ROS planner/apps
                     |
                     +---- QGroundControl (standard MAVLink UDP/TCP, unchanged)

custom GCS app <-> companion-gcs-api (HTTPS REST + read-only WebSocket, mTLS)
\end{lstlisting}

\begin{itemize}
  \item MAVROS is the sole MAVLink-to-ROS adapter.
  \item MAVLink Router is the sole FC-to-QGroundControl transport.
  \item The companion API is for a project-owned GCS application. It does not
        replace QGroundControl and must not add a MAVLink dialect or raw MAVLink
        injection endpoint.
  \item ARM64 images are built only on the WSL workstation, then transferred to
        the Pi using \pathtext{docker save | ssh | docker load}. Never build on Pi.
\end{itemize}

\subsection{Implemented API contract}

Read-only endpoints:

\begin{lstlisting}
GET /v1/health
GET /v1/services
GET /v1/services/{service}/logs?tail=200
GET /v1/stream/services              # WebSocket
GET /v1/stream/logs?service=...      # WebSocket
\end{lstlisting}

Only named Compose services can be queried. Log output is redacted for common
secret patterns. The API accepts no shell command, arbitrary Docker identifier,
or raw MAVLink payload.

Future typed control routes currently exist only as a disabled contract:

\begin{lstlisting}
POST /v1/control/arm
POST /v1/control/mode
POST /v1/control/mission
POST /v1/control/offboard/session
POST /v1/control/offboard/setpoint
POST /v1/control/abort
\end{lstlisting}

They currently return \pathtext{409 capability\_disabled}; no FC command is sent.

\subsection{Important deployment caveat}

The prototype uses Docker CLI internally, but Compose deliberately does not
mount \pathtext{/var/run/docker.sock}. Therefore it is safe-by-default but cannot
return live service/log data after deployment yet.

Before deployment, implement exactly one reviewed option:

\begin{enumerate}
  \item \textbf{Recommended:} a host-side read-only collector that writes
        sanitized status/log events to a shared read-only file or socket.
  \item A narrowly scoped Docker socket proxy exposing only container inspection
        and log-read endpoints, with every mutating endpoint blocked.
\end{enumerate}

Never mount the raw Docker socket in the network-facing API container.

\section{Future Planner-to-FC Control Plane}

A planner will eventually use typed ROS interfaces above MAVROS. No generic
command API and no raw MAVLink transmitter will be added.

Every control operation must have:

\begin{itemize}
  \item mTLS identity and RBAC authorization;
  \item a request ID and explicit confirmation;
  \item a versioned capability policy;
  \item connection/state/mode/freshness preconditions;
  \item strict timeout and rate limiting;
  \item immutable audit evidence with MAVROS/PX4 result;
  \item an operator abort path.
\end{itemize}

Offboard operation must be a dedicated state machine: pre-stream setpoints,
verify mode transition, maintain freshness/watchdog, abort upon planner loss or
timeout, and provide immediate operator abort.

\section{Mandatory Validation Gates}

The user stated that propellers have been removed for bench work. This reduces
risk but does not authorize arbitrary control or flight operation.

Before enabling each individual capability (arm, disarm, mode, mission,
offboard session, offboard setpoint, abort), validate:

\begin{enumerate}
  \item correct target vehicle identity;
  \item accessible power disconnect and kill/abort procedure;
  \item RC/manual override and PX4 failsafe behavior;
  \item mTLS rejection, RBAC denial, missing confirmation and stale-state denial;
  \item policy expiry, timeout and rate limits;
  \item audit record, MAVROS result and return-to-safe state.
\end{enumerate}

Flight-ready authorization requires a separate review, including SITL,
geofence, loss-link behavior, battery/GPS criteria, and operational risk review.

\section{Non-Negotiable Constraints}

\begin{itemize}
  \item Never build ARM64 images on Pi.
  \item Do not replace QGroundControl or create another GCS MAVLink transport.
  \item No custom MAVLink dialect or raw MAVLink injection.
  \item Do not broadly clean Docker or restart unrelated services.
  \item Never commit secrets, authentication keys, certificates, or private keys.
  \item No public exposure, Tailscale Funnel, exit node, or subnet route.
  \item Keep \pathtext{/camera} independent from Vision.
\end{itemize}
